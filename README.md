# Employee Management System (EMS)

An **Employee Management System (EMS)** built using **React**, **Vite**, and **Tailwind CSS**. This project features separate dashboards for administrators and employees, allowing task assignment and tracking through a clean and responsive interface.

---

## 🚀 Features

### 👨‍💼 Admin

* Secure admin login
* Create and assign tasks to employees
* View all assigned tasks
* Monitor employee task status

### 👨‍💻 Employee

* Secure employee login
* View assigned tasks
* Track task progress
* View task details
* Responsive dashboard

### 📋 Task Management

* New Tasks
* Active Tasks
* Completed Tasks
* Failed Tasks
* Task summary cards

### 🎨 User Interface

* Modern design
* Responsive layout
* Dark theme
* Built with Tailwind CSS

---

## 🛠️ Tech Stack

* React.js
* Vite
* Tailwind CSS
* JavaScript (ES6+)
* Context API
* Local Storage

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/chiragsharma777/employee-management-system.git
```

### Go to the project folder

```bash
cd ems
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:5173
```
